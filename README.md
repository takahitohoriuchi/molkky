# MÖLKKY NOTE

映像・ゲームログ・スキットル配置を連動させて、モルックの試合を一投ずつ振り返るブラウザアプリです。

## 画面構成

- **タイトル**：「モルックをプレイする」「モルックデータを鑑賞する」から選択します。
- **モルックをプレイする**：工事中。プレイ機能は将来実装します。
- **データ読み込み**：動画・ゲームログ・任意のスキットル位置情報を選びます。
- **データ鑑賞**：動画・スキットル可視化・ゲームログの3エリアで試合を振り返ります。動画とログのハイライトは相互に連動し、配置図も対応する試技の状態へ切り替わります。

## 起動

Node.js 18以上で、このフォルダーから実行します。外部パッケージのインストールは不要です。

```sh
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。終了はターミナルで Ctrl+C。

## GitHub Pagesでの利用

ビルド不要の静的アプリです。HTML・CSS・JavaScriptを配信すれば利用できます。公開サイトでは「モルックデータを鑑賞する」から、自分の動画とCSVをドラッグ＆ドロップまたはファイル選択で読み込みます。ファイルはブラウザ内で処理されます。

同梱データやサンプル専用機能への依存はありません。自分の動画・CSVを用意して読み込んでください。

### ローカルと公開先で動作が異なる場合

GitHubの Settings → Pages で、公開元のブランチ・フォルダーを確認してください。作業ブランチに修正があっても、公開元に反映されていなければサイトは更新されません。GitHub Actionsを使う設定の場合は、ワークフローがどのブランチ・成果物を配信しているか確認します。

この作業フォルダーでは修正が `master` にあり、`main` に旧版が残っている状態が確認されました。公開元が `main` なら、修正を `main` にマージしてpushするか、公開元を修正済みブランチに合わせてください。

再デプロイ完了後、公開HTMLの末尾が `app.js?v=20261020-7` を参照していることを確認してください。`v=20261020-5` のままなら旧版が配信されています。公開HTMLが更新済みでもブラウザが古い版を表示する場合は、キャッシュを無視して再読み込み（Macでは Cmd+Shift+R）してください。

## データの読み込み

動画とゲームログは必須、スキットル位置CSVは任意です。それぞれローカルファイルのクリック選択・ドラッグ＆ドロップ、またはURLを利用できます。ファイルとURLは混在できます。最後に選んだ入力方式が優先されます。

- 動画: ブラウザが対応するMP4 / WebM等。URLは動画ファイルの直接URLを使います。YouTubeの視聴ページやGoogle Driveの共有ページは使えません。
- ゲームログ: UTF-8のCSV、CSVの直接URL、公開してアクセスできるGoogleスプレッドシートURL。
- 位置情報: UTF-8のCSVまたはCSVの直接URL。

クラウドCSVは、配信元でブラウザからのアクセス（CORS）が許可されている必要があります。Googleスプレッドシートはサインインなしで取得できる共有設定が必要です。アクセスできない場合はCSVとしてダウンロードしてローカルで読み込んでください。ローカルファイルはブラウザ内で処理され、アップロードされません。クラウドURLのデータは配信元から取得します。

## ゲームログCSV

ゲームログ作成側の以下の列名を、そのまま読み込めます。

| 実データの列 | 表示・解釈 |
| --- | --- |
| `timestamp` | `YYYY/MM/DD HH:mm:ss` は日本時間（UTC+09:00）。端末のタイムゾーンによらず解釈 |
| `game`, `goal_score` | ゲーム名と目標点を鑑賞画面の見出しに表示 |
| `turn` | 試技ID。欠番があってもそのまま表示。位置CSVも `turn` を使用可能 |
| `team`, `player` | チームと投擲者を別々の列に表示 |
| `pins` | 引用符内のカンマ区切りに対応。空欄はミス |
| `throw_score` | 記録された試技の得点を優先 |
| `score_before`, `score_after` | 累計を「前 → 後」と表示 |
| `consecutive_misses` | 1以上のとき連続ミス回数を表示 |
| `over_goal`, `win`, `disqualified` | TRUE/FALSE（1/0も可）。それぞれ目標点超過・勝利・失格を表示 |
| `note` | 任意のメモ列。既存CSVの末尾などに追加可能。省略すると空欄 |

noteを追加する場合は、ヘッダーだけでなく各データ行にも列を1つ追加してください。メモ中のカンマはCSVの引用符で囲みます。元の実データファイルは変更していません。

従来の簡易形式も引き続き利用できます。以下が記述例です。

```csv
throw,timestamp,player,pins,score,total,note
1,00:05,チームA,7,7,7,7番を狙う
2,00:12,チームB,10;11;12,3,3,中央を狙う
3,00:20,チームA,,0,7,ミス
```

| 列 | 意味 |
| --- | --- |
| `timestamp` | 必須。秒数、`mm:ss`、`hh:mm:ss`（小数秒も可）、`YYYY/MM/DD HH:mm:ss`（日本時間）、タイムゾーン付きISO日時。例: `2026-10-20T13:00:00+09:00`。重複なしの昇順 |
| `throw` | 試技ID。省略時は1から連番。位置CSVと対応させる場合は一意のIDを指定 |
| `player` | プレイヤーまたはチーム名 |
| `pins` | 倒れた番号（1〜12）。複数は `;` 区切り、空欄はミス。CSVの引用符内ならカンマ区切りも可 |
| `score` | 得点。省略時は1本ならその番号、複数なら本数、ミスなら0を表示 |
| `total` | 累計。任意。50点超過等のルールを独自計算せず記録された値を表示 |
| `note` | メモ。任意 |

日本語の列名 `試技,タイムスタンプ,プレイヤー,倒れたスキットル,得点,累計,メモ` も使えます。`time` / `時刻`、`team` / `チーム`、`skittles` も対応します。

## スキットル位置CSV

以下の形式で、試技後のスキットル位置を指定します。

```csv
throw,pin,x,y
1,7,-80,-125
2,10,0,50
```

試技後の位置を指定します。`throw` はゲームログの試技ID、`pin` は番号、`x` は右向き、`y` は下向きの座標です。任意単位で、初期配置の隣接間隔は約46、描画円の半径は18です。`x/y` は±10000以内。初期配置を起点に、記載のない番号は直前の配置を引き継ぎます。

対象の試技で倒れた番号は、移動前を点線円、移動後を黒塗り・白数字で表示します。位置データがない場合は同じ位置に重ねます。立っているスキットルは黒枠・白地・黒数字です。

## 鑑賞と同期

- 各行のタイムスタンプはその試技の終了時刻です。試技nは、直前行の終了時刻以上、その行自身の終了時刻未満の区間でハイライトされます。終了時刻ちょうどで次の行へ移ります。最終行は試合終了後も表示を維持します。
- ログの行をクリック、またはキーボードでフォーカスしてEnterを押すと、直前の試技の終了時刻（その試技の開始位置）へジャンプします。先頭行は直前の行がないため動画0秒へ移動します。
- Spaceで再生・停止、左右矢印で1フレーム相当の時間を移動します。コマ送りは30fps相当（1/30秒）です。ブラウザのシークを用いるため、可変fps動画などでは厳密なフレーム単位にはなりません。
- ログの最初の試技の終了時刻を動画0秒に仮合わせします。最初の試技を含めて正しく鑑賞するには手動同期してください。
- 手動同期: ログパネルのタイトル行にある「同期調整モード」スイッチをオンにすると動画を一時停止し、動画とログの連動を解除し、ページ背景を暗くします。操作する各パネルは明るいままです。ログ行のクリックはハイライトだけを変更し、動画の再生・シークはハイライトに影響しません。両方を独立して調整し、「同期」を押すと、ハイライト行自身の終了タイムスタンプと動画の現在フレームを結びつけて通常の連動へ戻ります。何度でも同期し直せます。スイッチをオフにするだけなら変更を確定せず、従来の同期で連動に戻ります。
- 同期完了後は終了時刻を基準に追従が再開するため、試技nの終了位置では次の試技の行がハイライトされます（最終試技は除く）。
- 同期対象・同期ボタン・同期状態などの詳細とガイドは、同期調整モード中だけ表示します。
- 同期調整モード中のガイド：
  1. ログ表で、**試技n**をクリックしてハイライト状態に
  2. 動画で、**試技n**のログが登録されたであろうタイミングで一時停止
  3. この状態で同期ボタンを押す！

- 「同期を解除」で最初の試技の終了＝動画0秒に戻ります。動画の範囲外になった試技はエラーを表示し、手動で同期し直せます。
- 「現在の試技を追従」がオンなら、動画に合わせて現在行が見える位置まで表内を自動スクロールします。オフにすると、再生中でもログを自由にスクロールできます。
- 配置図はマウスホイール・トラックパッドのピンチ・2本指ピンチで、カーソルまたは指の中央を中心にズームできます。＋/−とリセットもあります。

動画は音声オン・音量100%で読み込みます。音量やミュート、再生操作は動画標準コントロールで調整できます（音声のないファイルには音は付きません）。

動画・スキットルエリアはそれぞれ上下左右の縁と右下をドラッグしてサイズ変更できます。縁にキーボードフォーカスして矢印キーでも調整できます。横幅が収まらない場合は下の段に回り込みます。「サイズをリセット」で元の配置に戻ります。

データ・同期設定はメモリ上のみで保持します。再読み込みすると消えます。

## 日時エラーが出る場合

実データの `2026/09/28 15:18:07` はそのまま読み込めます（日本時間）。ほかに `83`、`01:23`、`00:01:23`、`2026-09-28T15:18:07+09:00` も利用できます。

エラーに `YYYY/MM/DD HH:mm:ss` の案内が含まれない場合、古いプログラムが表示されている可能性があります。アプリのページを再読み込みしてください。改善しなければキャッシュを無視して再読み込み（Macでは Cmd+Shift+R）し、起動した作業フォルダーとURLを確認してください。
