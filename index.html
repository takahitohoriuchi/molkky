MATCH REVIEW / IMPORT

動画

振り返りたい試合の映像

または URL

動画ファイルの直接URL

02必須

ゲームログ

試技・時刻・得点の記録

または URL

公開されたスプレッドシート、またはCSVの直接URL

03オプション

スキットル位置

試技ごとの配置の変化

または URL

CSVの直接URL。省略すると初期配置を表示

ⓘ クラウドのデータは、公開設定や配信元のアクセス許可が必要です。

CSVの形式

実データ形式: timestamp（YYYY/MM/DD HH:mm:ss・日本時間）, turn, team, player, pins, throw_score, score_before, score_after など。noteは任意で追加できます。従来のthrow / score / total形式も使えます。時刻は重複なしの昇順。

位置情報: throw, pin, x, y。試技後の位置を指定します。省略された番号は直前の位置を引き継ぎます。xは右、yは下が正です。
